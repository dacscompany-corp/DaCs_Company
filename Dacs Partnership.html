MVP Specification
Portal Features & System Specification
DACS Client Portal & KPI Dashboard System — Minimum Viable Product (MVP) Terms & Features
1 System Overview

The system provides a Client Portal that enables users to monitor project progress, financial status, and performance metrics through structured modules such as SOA, Accomplishment Reports, Milestone Tracking, and KPI Dashboard. All data presented to the client must be validated by the admin (DACS) prior to visibility.

2 Statement of Account (SOA) Module

The SOA feature provides:

  • All financial transactions including payments, expenses, and remaining balance.
  • Cost breakdown into categories such as labor, materials, and other expenses.
  • A clear and organized financial summary for client review.
3 Accomplishment Reports Module

The Accomplishment Reports feature includes:

  • Periodic updates (weekly or milestone-based).
  • Completed tasks, descriptions, dates, and progress percentages.
  • Serves as the basis for progress tracking and KPI computation.
4 Milestone Progress Tracking with Notifications

The Milestone Tracking Module:

  • Divides the project into defined milestones with corresponding percentages.
  • Tracks completion status per milestone.
  • Sends push notifications when a milestone is updated, completed, or delayed.
  • Notifications are accessible within the client portal.
5 Project Overview Dashboard

The Project Overview Dashboard displays:

  • Total budget, total expenses, and remaining balance.
  • Overall project progress.
  • Milestone status summary and recent updates.
  • Acts as the main entry point for client monitoring.
6 KPI Dashboard — Performance-Based Metrics

The KPI Dashboard measures actual project performance using computed indicators. Included KPI metrics:

  • Project Completion Rate — (Completed Milestones ÷ Total Milestones) × 100
  • Budget Utilization Rate — (Total Expenses ÷ Total Budget) × 100
  • Schedule Performance Indicator — (Actual Progress ÷ Planned Progress) × 100
  • Cost Variance — Budget − Actual Cost
  • Weekly Progress Growth — Current Progress − Previous Progress
● Green = On Track ● Yellow = Warning ● Red = Critical

KPIs are automatically computed using data from the SOA Module (financial), Accomplishment Reports (progress), and Milestone Tracking (schedule). The dashboard supports filtering by weekly, monthly, or per milestone view.

Weekly totals (labor, materials, payments) are not classified as KPIs — they remain as supporting reports only.
6.4 KPI Alerts

The system generates alerts when:

  • Budget exceeds defined limits.
  • Project falls behind schedule.
  • No progress updates are recorded within a set timeframe.

Alerts appear in the notification panel.

7 Client Portal Login & Authentication
  • Secure login using registered credentials.
  • Proper error handling for invalid login and session expiration.
  • Access control — clients can only view their assigned projects.
8 Buyer Identification Requirement

Each project must have a registered buyer classified as either:

  • Individual User, or
  • Company / Organization

Required buyer details must be completed before any transaction or project activation.

9 DACS Review & Validation
  • Admin validates SOA entries, reports, and milestone updates.
  • Only approved data becomes visible to the client.
  • Ensures accuracy, transparency, and accountability.
10 System Scope (MVP Limitation)

This MVP is scoped to:

  • Client-side monitoring and viewing features only.
  • Basic KPI computation — no advanced analytics, forecasting, or automation beyond this.
  • Priority on clarity, usability, and essential tracking functions.
